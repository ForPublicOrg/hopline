Hopline is group chat for places with no mobile signal and no WiFi: treks, camps, festivals, village fairs, power cuts.

Phones link to each other directly over Bluetooth and WiFi, and every phone passes messages along for the others. A message can travel down a whole line of hikers, far beyond the reach of any single phone.

No internet. No mobile signal. No account. No server. No hotspot to set up.

HOW IT WORKS
- One person starts a group and gets a 3-word code, like "tiger river lamp".
- Everyone else types the three words (or scans the QR). Done.
- One group chat, like a WhatsApp group. Tap a name for a private chat.
- Phones find each other on their own. Walk away and come back - the chat catches up by itself.

HONEST STATUS UNDER EVERY MESSAGE
"Waiting for a phone in range", "Sent", "Reached 7 of 9", "Delivered" - a double tick only when the other phone really has it.

HELP BUTTON
Hold for 2 seconds and every phone in the group buzzes and shows a red screen with your name and which phones you are near. This only reaches your own group - it does not call rescue services.

THE OUTSIDE WORLD
If anyone in the group has internet, everyone can use a sliver of it: get the weather, read a web page as plain text, or send an SMS/email home through the friend's phone. The answer hops back to the whole group.

LIMITS, STATED PLAINLY
- Each hop is Bluetooth range: about 20-40 m in the open.
- Android only. iPhones cannot join.
- No end-to-end encryption - anyone with the 3-word code is in the group.
- Bluetooth is flaky; links can take up to a minute to form.
- Text only, on purpose.

Open source (MIT). Install it on every phone before you leave signal.
